Log expenses into a Google Sheet by sending a voice note, text or receipt photo to a Slack DM.

## Code rules (set by Mauro)

- Small, single-responsibility files. Aim for under 100 lines. 150 lines is unacceptable.
- No barrel files: every `__init__.py` stays empty; import from the module that defines the thing.
- Orchestration files (wiring modules together) are welcome.
- Everything in the repo is in English: code, comments, tests, eval cases, docs, prompts and logs (decided 2026-10-25 by Mauro). Mauro's own Spanish values (headers, categories) live only in his gitignored `config.yaml`.
- Python 3.12 managed by `uv`. The system default is 3.14, which many libraries do not support yet.

## Mauro's sheet (development reference only)

> Personal example used while developing. The code must read headers and categories from the connected sheet and never hardcode them. Step 11 removes these details from the repo.

Four columns, header on row 1, filters on. The exact header names and the 12 categories are in Mauro's gitignored `config.yaml` (`sheets.columns`, `sheets.fallback_categories`); they are Spanish and some categories have accents, so exact spelling matters.

| Col | Role | Type | Notes |
|---|---|---|---|
| A | date | date, shown `d/m/yyyy` (format set per cell, not on the column) | Taken from system time in `America/Bogota` (UTC-5). Never from the speaker. |
| B | amount | number | Colombian pesos, in practice whole numbers. Display format `$#,###` is already on the sheet; write a plain number. |
| C | category | dropdown chip | One of the 12 dropdown options. |
| D | description | free text | Short merchant or item name. |

Traps to handle:
- Writing a date as text like `05/10/2026` can be parsed as May 10 if the sheet locale is US. Write a serial number and verify.
- Column F and below the table may contain other content (the cursor was on F223). Append to an explicit next empty row in the four mapped columns, never rely on auto table detection.
- Amounts are spoken as plain numbers. A misheard amount (for example twenty instead of twenty thousand) is not caught by any check; the confirmation reply, which shows the row read back from the sheet, is where Mauro spots it.

## Deployment notes (cheap always-on Linux server)

Estimates from general knowledge, NOT measured. Step 11 includes a benchmark on the real server.

- **No inbound ports needed** (Socket Mode). Firewall everything except SSH. Run as a non-root user, `chmod 600` the Google key and the env file, load secrets through the service manager's environment file, enable automatic security updates.
- **With local speech-to-text:** the model file is 547 MB and whisper.cpp needs roughly 1 to 1.5 GB of RAM with it loaded, so aim for 2 vCPU, 4 GB RAM, 20 GB disk (2 GB RAM plus swap may work). Without a GPU, transcription is much slower than the 13 s measured on the M4; a short voice note could take tens of seconds on 2 vCPUs. x86 or ARM both work; build whisper.cpp natively on the server. Smaller or more quantized models (`small`, `base`) trade accuracy for speed.
- **Without speech-to-text** (text and photos only) the process is mostly idle and 512 MB to 1 GB of RAM is enough.
- **A hosted transcription API** would allow a tiny server but sends audio to a third party. Not chosen; Anthropic has no audio input.
- A Docker image that builds whisper.cpp is planned for portability (step 11). It is for servers; on a Mac, Docker cannot use the GPU, so run natively there.

## Target layout

Each line is one file. Keep it this way when adding code.

```
src/speech_to_sheets/
  config/    settings.py sections.py columns.py secrets.py errors.py
  slack/     client.py allowlist.py files.py thread.py replies.py
  stt/       run.py convert.py whisper.py transcript.py voice_note.py check.py errors.py
  extract/   inputs.py schema.py prompt.py content.py client.py errors.py sanity.py
  sheets/    client.py errors.py schema.py categories.py rows.py examples.py dates.py formats.py append.py read_row.py
  dedupe/    store.py prune.py errors.py
  pipeline/  bundle.py handle_message.py
  cli/       init.py prompts.py write_config.py
  main.py
tests/       one test file per module, plus test_file_length.py
scripts/     eval_extract.py (live extraction eval, costs real money), try_sheets.py (live Sheets check)
evals/       extract_cases.yaml (generic categories and example phrases only)
docs/        setup-slack.md  setup-google.md  deployment.md
deploy/      launchd and systemd examples, Dockerfile (step 11)
```

Flow: Slack DM event, then allowlist check and dedupe, then `bundle` (text + transcripts + images), then `extract` (Claude), then `sanity`. If complete: `sheets.append`, then `sheets.read_row` reads the written row back, then a Slack thread reply shows what was recorded, for example `Logged in row 224: 05/10/2026 | $45.20 | Food | Market`. If the entry is incomplete: reply with a question in the thread. If the write fails: reply with the error and do not say it was logged.

## Steps

### [x] 1. Scaffold
Create the project skeleton with `uv` (Python 3.12 pinned). Dependencies: `slack-bolt`, `gspread`, `google-auth`, `anthropic`, `pydantic`, `pyyaml`, `python-dotenv`; dev: `pytest`, `ruff`. Add `.gitignore` (at least `.env`, `config.yaml`, `*.json` keys, `*.wav`, `*.m4a`, `*.mp4`, `*.png`, `*.sqlite*`, `.venv`, `__pycache__`), `.env.example`, `config.example.yaml`, empty `__init__.py` files, and `tests/test_file_length.py` that fails when any `.py` file exceeds 150 lines and prints those over 100.
**Acceptance:** `uv run pytest` passes; `uv run ruff check` is clean; `git status` shows no secrets or ignored artefacts staged.

### [x] 2. Config and secrets
`config/settings.py` loads env vars (`.env` via python-dotenv) and `config.yaml`; `config/columns.py` holds the role-to-header mapping (`sheets.columns`). Settings: Slack bot/app tokens, allowed Slack user ID, Anthropic key, Google key path, sheet ID and tab name, `sheets.columns`, `sheets.fallback_categories`, whisper CLI, model path and language (default `auto`), timezone (default `UTC`), `dedupe` settings. All keys and defaults are in English; see `config.example.yaml`. Fail fast with a clear message when something is missing; never log secret values.
**Acceptance:** unit tests for missing/invalid config and defaults; `config.example.yaml` contains only generic example values (no personal categories or paths).

### [x] 3. Speech-to-text (whisper)
`stt/convert.py`: ffmpeg to 16 kHz mono wav (accept whatever Slack sends: m4a, mp4, ogg, etc.). `stt/whisper.py`: run `whisper-cli` via `subprocess` (no shell string building), return the transcript text, timeout, clear error if the binary or model is missing. The language comes from config (`stt.language`, default `auto`; Mauro sets `es`). Treat an empty or near-empty transcript as "no speech", never as an expense.
Do NOT write, generate or record audio tests or fixtures (Mauro's rule): no `say`-generated files, no sample recordings, no STT accuracy eval. Unit-test only with the subprocess mocked (command built correctly, timeout, missing binary or model, empty transcript). Accuracy is judged by Mauro using the real bot once the MVP works; if it fails he will tweak (for example `-l`, whisper's `--prompt`) from real failures.
**Acceptance:** unit tests pass with `subprocess` mocked; no audio files exist in the repo.

### [x] 4. Extraction (Claude)
`extract/schema.py`: result is either `Complete{amount: Decimal, category: enum, description: str}` or `NeedsInfo{question: str}`. The enum is built at runtime from the categories read from the sheet (`sheets/schema.py`). `extract/prompt.py`: English instructions only, no slang or locale hints; the sheet's own last rows are the few-shot examples, in whatever language the user writes. `extract/client.py`: call `claude-haiku-5-5` with structured output (`output_config.format`) and image blocks when present; set `output_config.effort` to `low` (Haiku 5.5 defaults to `medium` with thinking on); do not send `temperature`/`top_p`/`top_k` or an assistant prefill. Check the live API docs before writing the call; the SDK drifts. `extract/sanity.py`: category must be in the enum and the amount must be more than zero; otherwise the bot asks.
**USER:** needs an Anthropic Console API key with a small prepaid balance and a monthly spend limit.
**Acceptance:** unit tests with a fake client cover spoken-number amounts, missing amount, unknown category, image input; a live eval script over about 20 phrases is run once and results noted in the Status log.

### [ ] 5. Google Sheets
`sheets/client.py` (`open_worksheet`: service account auth with the Sheets scope only, once at startup; errors name the service account email to share the sheet with), `sheets/errors.py` (`SheetsError`; `google_errors` turns API, auth and network errors into one readable message), `sheets/schema.py` (read row 1 and locate each role's column by its header text, ignoring case and surrounding spaces; fresh read on every message, no cache; fails listing every missing or duplicated header and the headers found), `sheets/categories.py` (the category dropdown options from the data validation of the first data row, a list or a range; `sheets.fallback_categories` when unreadable), `sheets/rows.py` (`DisplayedRow`, last filled row of the date column, rows read as displayed), `sheets/examples.py` (last N rows), `sheets/dates.py` (date in the configured timezone to serial number), `sheets/formats.py` (number formats for the new row's date and amount cells, copied from the row above; only number formats, never colors; the date falls back to the locale's default date format), `sheets/append.py` (next empty row from the date column; one `spreadsheets.batchUpdate` of `updateCells`, so Google applies all of it or none; writes only the four mapped cells, values as `numberValue`/`stringValue` so text is never run as a formula; a lock so two Slack threads never pick the same row; returns the row number), `sheets/read_row.py` (read that row back as displayed, for the confirmation message). Confirm against Mauro's duplicate that the Sheets API really returns the chip values (the API reference does not mention chips), otherwise use `sheets.fallback_categories`.
**USER:** follow `docs/setup-google.md`: create a Google Cloud service account and JSON key, duplicate the real sheet, share the duplicate with the service account email, then set `sheets.sheet_id` and `sheets.tab` in `config.yaml` and `GOOGLE_SERVICE_ACCOUNT_FILE` in `.env`. If the Google account is a Workspace org, key creation may be blocked by policy (Google enforces it by default for orgs created on or after 2024-05-03): report it.
**Acceptance:** run `uv run python scripts/try_sheets.py --append` against the duplicate; confirm date displays like the rows above (`d/m/yyyy` on Mauro's sheet), the amount is numeric and formatted, the category chip renders, nothing outside the mapped columns is touched; the categories read from the sheet match the dropdown. Delete the test row afterwards.

### [ ] 5b. Init command
`uv run speech-to-sheets init` creates `config.yaml` interactively. `cli/init.py` (orchestrator), `cli/prompts.py` (ask, confirm and choose helpers, injectable so tests can script answers), `cli/write_config.py` (writes `config.yaml`; asks before overwriting; never writes secrets). Flow: load the secrets from `.env`, connect to the sheet ID given, list tabs and ask which one, read row 1, propose a role-to-header mapping by best guess (names like date, amount, category, description in any language) and let the user confirm or pick from the headers found, read and show the dropdown options of the category column (if unreadable, ask for a list to store as `fallback_categories`), ask timezone and STT language, write `config.yaml`. `main.py` dispatches the `init` subcommand (wired in step 8). Reuse `sheets.client.open_worksheet` and `sheets.categories.read_categories`; `sheets.schema.find_layout` checks the confirmed mapping.
**Acceptance:** tests with scripted answers and a fake sheet cover a clean mapping, a wrong guess corrected by the user, unreadable dropdown, existing config not overwritten without confirmation; run once against Mauro's duplicate sheet and the generated config works.

### [x] 6. Dedupe store
`dedupe/store.py`: SQLite file (gitignored), table of Slack message ID, status (`pending`, `done`, `failed`), sheet row and created-at. API: `claim(message_id) -> bool` (atomic insert, `False` if already present), `finish(message_id, row)`, `fail(message_id)`. `dedupe/prune.py`: `prune(older_than_days)`, called once at startup. The `dedupe` section (`retention_days`, `path`) already exists in `config.example.yaml`.
**Acceptance:** tests for first claim, repeat claim, finish and fail, persistence across restarts, and pruning that deletes only old entries.

### [ ] 7. Slack app
Write `slack-app-manifest.yaml` and `docs/setup-slack.md`. Needs: Socket Mode, Messages tab enabled in App Home, event `message.im`, scopes `im:history`, `files:read`, `chat:write`.
**USER:** create the Slack app from the manifest, install it, copy the bot token (`xoxb-`) and app-level token (`xapp-`) into `.env`, give the agent their Slack user ID.
Code: `slack/client.py` (Bolt app), `slack/allowlist.py`, `slack/files.py` (download with the bot token in the Authorization header), `slack/thread.py` (rebuild a thread), `slack/replies.py`.
Photos: the API accepts only JPEG, PNG, GIF and WebP, at most 5 MB each (`extract.inputs.Image` rejects other types). iPhone photos can be HEIC or larger than 5 MB. Check what Slack actually delivers; Slack's JPEG thumbnails (for example `thumb_1024`) may be enough for a receipt. Not verified yet.
**Acceptance:** the bot connects and echoes a test DM from Mauro's phone; messages from any other user are ignored; unit tests for allowlist and thread rebuilding.

### [ ] 8. Pipeline and entry point
`pipeline/bundle.py` (text + transcripts + images into one extraction input), `pipeline/handle_message.py` (orchestrator: allowlist, dedupe, bundle, extract, sanity, append, read the row back, send the confirmation or the follow-up question), `main.py` (wire and start). The orchestrator calls `claim()` first and stops if it returns `False`; it calls `finish()` only after the append succeeded (the confirmation is sent after that) and `fail()` on any handled error. Call `stt.check.check_stt` at startup. Extraction is `extract.client.extract` then `extract.sanity.check`; the thread becomes `Turn`s (bot messages as `author="bot"`, transcripts with `voice=True`).
Sheets wiring: `open_worksheet` once at startup; per message `read_layout`, `read_categories(worksheet, layout.category, fallback)`, `read_examples` (convert each `DisplayedRow` to `extract.inputs.ExampleRow`; `sheets` does not import `extract`), `append_entry(day=today_in(timezone), ...)`, then `read_row`. `SheetsError` and `DedupeError` are handled errors. A write error can come after Google already stored the row (for example a timeout on the reply), so the error message must tell the user to check the sheet before resending.
Duplicate trap: re-reading a thread that already got a confirmation would extract the same expense again. A reply in a thread that already has a confirmation must never log another row (for example, reply that the entry is already logged).
**Acceptance:** with fakes for Slack, whisper, Claude and Sheets, tests cover: text only, voice only, photo only, `NeedsInfo` then a follow-up reply completing it, confirmation text shows the values read back from the sheet, write failure sends an error and no confirmation, duplicate event ignored, empty transcript, non-allowlisted user, a reply in an already-logged thread writes no row.
